# Banquier FR — французька для банківського працівника (A1 → A2 → B1)

Офлайн-застосунок для підготовки до роботи в банку у Франції: банківська лексика, діалоги з клієнтами, анімовані відео-сцени, розмовні фрази, вправи, тести й відстеження прогресу.

## Відкрити в браузері

**👉 https://volanderbo-stack.github.io/Banquier-FR/**

Працює в будь-якому сучасному браузері на комп'ютері й телефоні. Застосунок можна **встановити** як окрему програму — після цього він працює й без інтернету:

- **Chrome / Edge на комп'ютері:** кнопка «⬇ Встановити застосунок» у меню зліва або значок «Встановити» в адресному рядку.
- **Android (Chrome):** меню ⋮ → «Встановити застосунок» / «Додати на головний екран».
- **iPhone / iPad (Safari):** «Поділитися» → «На початковий екран».

## Запуск локально

- двічі клацніть `start.bat` — запуститься локальний сервер і застосунок відкриється на `http://localhost:8765`. Так працює і озвучення, і мікрофон (рольові ігри, відповіді у відео).
- **Без сервера:** просто відкрийте `index.html` у Microsoft Edge або Google Chrome. Озвучення працює, мікрофон — найімовірніше ні.

Прогрес зберігається в браузері окремо для кожного способу запуску (localhost і файл — різні «сховища»), тож обирайте один. Перенести прогрес можна через **Прогрес → Зберегти / Відновити з файлу**.

## Голоси

Застосунок використовує французькі голоси системи (Web Speech API). Найприродніше звучать голоси «Natural/Online» у Microsoft Edge. Якщо французьких голосів немає: Windows → Параметри → Час і мова → Мовлення → Додати голоси → Français (France). Голоси для жіночих і чоловічих персонажів обираються в **Налаштуваннях**.

## Що всередині

| Розділ | Вміст |
|---|---|
| Модулі | 7 тем (рахунки, картки, кредити, страхування, ліміти, ризики, вклади) × 3 рівні: лексика → діалог → відео → фрази → вправи → тест |
| Словник | 212 термінів FR–UA з озвученням, прикладами, поясненнями французьких реалій |
| Картки | інтервальне повторення (слово «вивчене» після 3 правильних відповідей поспіль) |
| Діалоги | 21 діалог «клієнт — працівник банку» з перекладом і рольовою грою |
| Відео | 21 анімована сцена (кожна тема на кожному рівні) із вигаданими персонажами; субтитри FR/UA, нові слова, вправа «відповісти замість працівника» |
| Фрази | 71 фраза: привітання, уточнення, пояснення, ввічлива відмова, скарги, телефон |
| Вправи | переклад, аудіювання, написання, пропуски, порядок слів, пари, відповідь клієнту, суми на слух |
| Тести | тест кожного модуля (12 запитань) та іспит рівня (25), залік — 80 % |
| Граматика | 16 тем, потрібних банкіру (vouvoiement, conditionnel, subjonctif, гіпотеза…) |

Банк «Banque Mirabelle» і всі персонажі вигадані. Ставки й тарифи в діалогах — навчальні; правила (ліміти Livret A/LDDS, норма 35 %, строки на роздуми) варто перевіряти на актуальність.

## Структура

- `index.html`, `css/styles.css`
- `js/data/` — контент: `vocab.js`, `dialogues.js`, `videos.js`, `phrases.js`, `grammar.js`, `characters.js`, `topics.js`
- `js/scene.js` — генерація SVG-персонажів і відеоплеєр; `js/speech.js` — озвучення й розпізнавання мовлення
- `js/exercises.js` — генератор вправ і тестів; `js/store.js` — прогрес (localStorage)
- `js/app.js`, `js/views-*.js` — сторінки застосунку
